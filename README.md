# Radiance — Light Room

**Experience Radiance:** https://luckygithub777.github.io/radiance-light-and-form/

Stay in the Glow

Radiance is an original self-contained visual experience of luminous color, geometric forms, and continuous motion. The full Light Room opens at the homepage, with no intermediate page or required account.

- Forms: Pyramid, Sphere, Seed of Life, Flower of Life, Cube, Prism
- Color: Spectrum and five additional palettes
- Pattern: Linear or Waves
- Pace: Flow, Vivid, Surge
- Glow: Soft, Warm, Radiant
- Controls: Pause, Hide Controls, Fullscreen

Defaults are Spectrum, Linear, Surge and Radiant. The application is static HTML, CSS, SVG and JavaScript; there are no external scripts, analytics, trackers, APIs or running backend. Use **Save offline copy** to keep the entire application in one HTML file.

## Verification and limits

Source integrity, local link checks, security hashes and interaction tests run in GitHub Actions. See [QUALITY.md](QUALITY.md) for the release checks and remaining device-specific tests.

Radiance is a contemplative visual experience, not a clinically validated light-therapy device. Claims of specific health effects require independent evidence.
